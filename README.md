# cck

Unity toolkit for chat/dialog components plus the MCP pipeline used to drive Unity and Blender from an LLM agent.

- Unity scripts: `CckChatListener`, `CckChatLogger`, `CckDialog`, `CckDialogLightToggle`, `CckFloatingText` (docs in `README_cck_*.md`); packages `CCK_4.0.1_Release.unitypackage`, `pakkio.unitypackage`
- MCP: `mcp-unity-server/`, `mcp-pipeline/`, `mcp_bridge-2.3.4.zip`, `opencode.json`, `skills/` (see also [mcp-unity](https://github.com/pakkio/mcp-unity), [mcp-cck](https://github.com/pakkio/mcp-cck))
- Prompt notes: `MCP_BLENDER_UNITY_PROMPTS_ACTIVITY.md`

Setup (Python 3.12, Node 24, Windows 11): see [SETUP.md](SETUP.md).
